# WP Hierarchical Tags

[![Version](https://img.shields.io/badge/version-1.0.1-blue.svg)](https://github.com/tikhomirov/wp-tags-plugin/releases)
[![WordPress](https://img.shields.io/badge/WordPress-4.6%2B-blue.svg)](https://wordpress.org/)
[![PHP](https://img.shields.io/badge/PHP-7.4%2B-purple.svg)](https://php.net/)

Adds hierarchical (tree) tags support for WordPress posts with shortcode output.

## Requirements

| Component | Minimum | Tested |
|-----------|---------|--------|
| **WordPress** | 4.6 | 6.8 |
| **PHP** | 7.4 | 8.x |

## Features

- Hierarchical post tags taxonomy behavior
- Shortcode `[tags]` for frontend output
- Composer package `rwsite/wp-tags-plugin`

## Installation

### Composer

```bash
composer require rwsite/wp-tags-plugin
```

### Manual

1. Download the [latest release](https://github.com/tikhomirov/wp-tags-plugin/releases).
2. Upload to `wp-content/plugins/wp-tags-plugin/`.
3. Activate **Hierarchical tags**.

## Usage

```
[tags]
```
